# v0.7.2 AI 备注整理

## 行为

AI 记账将口语整理成短语，以“·”分隔餐次、商户和具体内容，减少“去、买了、花了”等叙述用语。购物保留商户及商品，交通保留工具、线路及目的地，缴费保留费用用途。

| 输入 | 目标备注 |
| --- | --- |
| 中午吃饺子花了14.8元 | 午餐·饺子 |
| 去赵一鸣买零食花了20元 | 赵一鸣·零食 |
| 买零食花了8元 | 零食 |
| 吃饺子花了14.8元 | 饺子 |
| 坐地铁9号线去公司花了6元 | 地铁9号线·公司 |
| 昨天交了3.5元团费 | 团费 |

金额、交易日期仍分别记录，不在备注中重复。商品规格、数量、交通线路编号属于有意义的细节，需要保留。没有说餐次、店名或目的地时不补写；多笔账目各自整理，不能互相混入描述。

改进文字记账的备注提示规则，并明确相对日期参照、实际兜底分类编号，以及缴费与退款的区别，减少整理备注时的识别干扰。沿用现有模型和一次 API 请求，不新增二次润色请求或依赖。已有账目和手动备注保持原样，新的 AI 草稿仍由用户核对和编辑后确认保存。规则约束不等于所有自然语言都能稳定识别。

## 验证

真实接口测试沿用本地忽略的 Key 文件，只发送合成语句，不读取正式账本、不安装手机 App。文字验收包含原有 10 个日期、费用及排除场景，以及 10 个摘要场景，检查真实模型的金额、日期、具体内容、规范备注和关闭思考状态。包含提示示例中没有的商户、商品及口语表达，避免只验证示例复述。

```powershell
.\scripts\test-ai-local.ps1 -AllowLiveRequests -TextAccounting -Offline
.\scripts\build.ps1 :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --offline
```

`-Offline` 只控制 Gradle 依赖解析，真实接口测试仍需要联网。真实请求前应核实当前模型价格。
