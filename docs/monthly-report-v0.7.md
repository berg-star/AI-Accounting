# v0.7 月度消费报告

## 入口与展示

“统计 → 查看月度报告”，跟随当前选择的月份，也可在报告中切换月份。

1. 概览：收入、支出、净收支、笔数及明确起止日期。净收支是收入减支出，不代表余额。
2. 主要支出类别：金额、笔数、占比，点击查看对应账目；已停用分类仍保留历史统计。
3. 最大五笔支出：金额倒序，同金额按日期和记录 ID 倒序，点击打开原记录。
4. AI 总结：手动生成三到五条重点，点击“查看依据”打开本期全部、分类明细、原记录或两期分类记录。仅有收入时生成概览。

本月从月初统计到今天，历史月份统计完整自然月，未来月份不生成总结。已删除及本月未来日期的记录不计入。对照期是上月：当前月使用相同日号截至日期，上月没有对应日则取月底；历史月使用上月整月。两期天数不同会提示，不推断日均变化。

## AI 与本地分工

金额、笔数、占比、排名和差额全部在本地计算。AI 使用 `Qwen/Qwen3.5-4B`、`enable_thinking: false`，只选择有真实依据的重点，不生成不可验证的消费原因、评价、建议或银行余额。

AI 只能引用实际存在的分类、大额支出或非零变化分类；有支出时必须包含最大分类和最大单笔。结论重复、引用错误、缺少重点、超出五条、输出截断或格式错误时不保存。数字与文字由本地根据已校验的引用生成，每条都可打开依据。

只有点击生成按钮才调用接口。发送本期收支及分类汇总、最大五笔支出的日期/金额/分类/备注、上月分类汇总；不发送其他明细、收入备注或 Key 到模型内容。空账本不调用接口，手动记账和本地报告不要求 Key。

## 本机保存和更新

总结按月份保存在 App 私有文件，重开直接读取，不重复付费；写入使用原子替换。缓存只含月份、指纹、生成时间及结论引用，不保存原始备注、Key 或模型自由文字。

本期记录、被引用分类或上月对照记录变化，以及本月跨日时，重新计算本地数据，旧总结隐藏并提示更新。生成请求前后都检查数据，避免把过期结果保存成当前报告。离开页面、切换月份或 App 后台时取消请求；失败、取消及保存失败均保留本地统计，不冒充生成成功。

从证据页编辑上月记录或将本期记录移到其他月份后，返回原来的报告月份，重算并提示更新。恢复账本时清除旧总结，避免复用旧引用；此清理对同一次恢复是幂等的，旋转或重组不会再次删除刚生成的总结。报告不进入账本导出备份。
